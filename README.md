# Internship Management System — Student Application

## Overview

The Student Application is a web application that helps students discover internship opportunities, manage their professional profiles, and track their practical experience.

It connects students with companies offering internships and provides tools for preparing CVs, applying for opportunities, and receiving personalized internship recommendations.

## Features

Student Authentication: Provides login functionality for registered student accounts.

CV Management: Allows students to create and maintain their CVs, including personal information, education, additional training, work experience, skills, and interests.

Internship Search: Enables students to browse, search, and filter available internships by company and required technologies.

Internship Applications: Allows students to apply for available internship opportunities.

AI-Powered Recommendations: Displays personalized internship recommendations based on students' skills, interests, and CV information.

Work Diary: Enables students to record their activities and progress on a weekly basis.

Internship Details: Provides detailed information about internship opportunities, including descriptions, technologies, and requirements.

## Technology Stack

Frontend framework: Angular

Language: TypeScript

Backend: Java and Spring Boot REST API

Database: Managed through the backend

## Integration

The application communicates with the central Spring Boot backend through RESTful API endpoints. Student profiles, CV information, internship listings, applications, and recommendation results are managed through the shared system.

## Getting Started

Clone the repository.

Install the required dependencies.

Configure the backend API URL.

Start the development server using the commands appropriate for the selected frontend framework.

## Project Context

This application is one of four components of an Internship Management System developed as part of an Internet Programming university project at the Faculty of Electrical Engineering, University of Banja Luka.
